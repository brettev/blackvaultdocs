# App Router pages — BlackVaultDocs

Next.js App Router page components + layouts for `blackvaultdocs.com`.

Apply these instructions to `frontend/app/`. See `frontend/AGENTS.md` for
build + deploy details and `frontend/lib/api.ts` for data access.

## UX intent

Every route is SEO-first: crawlable as static HTML, with a canonical URL
and rich metadata. The homepage is the main entry for branded/category
search; collection and document pages capture the long tail (NARA record
IDs, release years, agency names).

## Routes

| Route | File | Generated by |
|---|---|---|
| `/` | `page.tsx` | static |
| `/about/` | `about/page.tsx` | static |
| `/stats/` | `stats/page.tsx` | static (fetches `/api/public/stats`) |
| `/search/` | `search/page.tsx` + `search/SearchBox.tsx` | static, client-side filter |
| `/topics/` | `topics/page.tsx` | static (lists all collections) |
| `/topics/<slug>/` | `topics/[slug]/page.tsx` | `generateStaticParams` from `listTopics` |
| `/topics/<slug>/page/<n>/` | `topics/[slug]/page/[page]/page.tsx` | per-topic pagination, `n ≥ 2` |
| `/documents/` | `documents/page.tsx` | static (recent docs) |
| `/documents/<slug>/` | `documents/[slug]/page.tsx` | `generateStaticParams` capped at `MAX_STATIC_DOCS` |
| `/agencies/` | `agencies/page.tsx` | static |
| `/agencies/<slug>/` | `agencies/[slug]/page.tsx` | `generateStaticParams` from `listAgencies` |

## Local conventions

- Export a `metadata` object (or `generateMetadata` for dynamic routes)
  with `alternates.canonical` on every route.
- Dynamic routes set `export const dynamicParams = false;` so unknown
  slugs 404 at build time instead of blowing up the runtime.
- Document detail pages emit `DigitalDocument` JSON-LD; topic detail pages
  emit `CollectionPage` JSON-LD. Update both if the schema shape changes.
- Keep nav entries in sync with `components/SiteChrome.tsx` and the
  footer's Browse list.
- Record-level detail on `/documents/<slug>/` should keep including: NARA
  ID (cleaned), source, collection, agency, classification (if present),
  release date, page count, file size, slug, indexed timestamp, PDF link,
  release-page link, NARA catalog search link, and an inline PDF preview.

## Gotchas

- Adding a new dynamic route requires a corresponding `generateStaticParams`
  or the build will fail under `output: "export"`.
- `params` is a `Promise` in Next.js 16 — always `await params` before
  destructuring.
- The prose on the homepage / about pages is hand-rolled (no
  `@tailwindcss/typography` usage). Keep paragraph spacing consistent with
  the existing pages if you add new prose surfaces.
